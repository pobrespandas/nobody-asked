# Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/pobrespandas/nobody-asked/security/advisories/new) when it is available. If the form is unavailable, ask a maintainer for a private channel. Keep vulnerability details out of public issues and pull requests.

Include the affected version or commit, the impact, and steps to reproduce the issue with test data. Remove credentials, private records, and personal information from the report.
